# Meridian Bank – Qt 6 Desktop GUI

مشروع واجهة رسومية لإدارة بنك باستخدام **C++17 وQt 6 Widgets**. يحتوي على تسجيل دخول، لوحة تحكم، إدارة عملاء، معاملات، وإدارة مستخدمين بصلاحيات Bitwise.

> **مشروع تعليمي للعرض والتعلّم فقط.** ليس نظامًا مصرفيًا حقيقيًا، ولا تستخدميه مع بيانات عملاء أو كلمات مرور أو أموال حقيقية.

## المميزات

- تسجيل دخول بالاعتماد على ملف المستخدمين المحلي.
- Dashboard يعرض ملخص العملاء والأرصدة وفق صلاحيات المستخدم.
- إدارة العملاء: عرض، بحث، إضافة، تعديل، وحذف.
- المعاملات: إيداع، سحب، وحساب إجمالي الأرصدة.
- إدارة المستخدمين والصلاحيات.
- التحقق من الصلاحيات داخل طبقة الخدمات، وليس بإخفاء الأزرار فقط.
- حفظ محلي بنفس فاصل السجلات الأصلي `#//#`.
- استخدام `QSaveFile` لتقليل احتمال تلف الملف أثناء الحفظ.

## المتطلبات

- C++17
- Qt 6 Widgets (الإصدار 6.2 أو أحدث)
- Qt Creator
- CMake (مفضّل) أو qmake

## ملفات المشروع

- `main.cpp`: نقطة تشغيل التطبيق.
- `LoginWindow.*`: واجهة تسجيل الدخول.
- `MainWindow.*`: النافذة الرئيسية والتنقل.
- `Pages.*`: صفحات Dashboard والعملاء والمعاملات والمستخدمين.
- `BankService.*`: قراءة البيانات والتحقق والحفظ والصلاحيات.
- `BankTypes.h`: هياكل بيانات العملاء والمستخدمين وثوابت الصلاحيات.
- `UiHelpers.h`: تنسيق الواجهات والمكونات المشتركة.
- `original_backend/`: نسخة من كود الـ Console الأصلي، وغير مضافة إلى Target واجهة Qt.
- `sample_data/`: بيانات تجريبية وهمية.

## تجهيز بيانات Demo لأول تشغيل

ملفا التشغيل `Bank.txt` و`users.txt` غير مرفوعين في Git عمدًا؛ لأنهما قد يحتويان بيانات شخصية أو كلمات مرور. أنشئي نسختين محليتين من القوالب التجريبية.

في PowerShell من مجلد المشروع:

```powershell
Copy-Item sample_data/Bank.txt.example Bank.txt
Copy-Item sample_data/users.txt.example users.txt
```

### حسابات تجريبية

| الدور | Username | Password | الصلاحيات |
|---|---|---|---|
| مدير تجريبي | `demo_admin` | `DemoOnly123!` | كل الصلاحيات |
| مستخدم محدود | `demo_viewer` | `ViewOnly123!` | عرض وبحث العملاء فقط |

بيانات الدخول دي معلنة للعامة ومخصصة للتجربة فقط؛ لا تستخدميها في أي نظام آخر.

## التشغيل من Qt Creator

1. ثبتي Qt 6 Widgets مع Compiler متوافق، مثل Qt 6.12 MinGW 64-bit.
2. افتحي `CMakeLists.txt` في Qt Creator.
3. اختاري Qt Kit المناسب.
4. اعملي Configure للمشروع.
5. اضبطي Run working directory على مجلد المشروع الذي يحتوي على `Bank.txt` و`users.txt` بعد إنشائهما من ملفات Demo.
6. اعملي Build ثم Run.

## صيغة البيانات والصلاحيات

- العميل: `AccountNumber#//#PinCode#//#Name#//#Balance`
- المستخدم: `username#//#password#//#permissions`
- الصلاحيات: `1, 2, 4, 8, 16, 32, 64`، والقيمة `-1` تعني Full Access.

## حدود المشروع وملاحظات الأمان

- كلمات مرور المستخدمين وأرقام PIN للعملاء محفوظة كنص عادي للتوافق مع تنسيق المشروع التعليمي الأصلي. لا يوجد Password Hashing أو تشفير للملفات.
- التخزين يتم في ملفات نصية محلية، وليس قاعدة بيانات.
- التطبيق يحدث الرصيد الحالي، لكنه لا يحتفظ بسجل تاريخي قابل للتدقيق لكل معاملة.
- المشروع مناسب للتعلم والعرض في Portfolio فقط، وليس للاستخدام البنكي الحقيقي أو الإنتاج.
- استخدمي بيانات وهمية فقط، ولا ترفعي ملفات `Bank.txt` أو `users.txt` الشخصية إلى GitHub.

## كود الـ Console الأصلي

الكود الأصلي محفوظ داخل `original_backend/`. الواجهة تستخدم `BankService` منفصلًا لأن دوال الـ Console تعتمد على `cin/cout` والقوائم النصية، ولا يصح استدعاؤها مباشرة من أزرار Qt.
